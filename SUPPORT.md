# Support

Need help with APIVerve? Here's how to get support.

## 📚 Documentation

Start with our documentation:
- **[API Documentation](https://docs.apiverve.com)** - Full API reference
- **[Getting Started](https://docs.apiverve.com/getting-started)** - Quick start guide
- **[FAQ](https://docs.apiverve.com/faq)** - Frequently asked questions

## 💬 Community

- **[GitHub Discussions](https://github.com/apiverve/apis/discussions)** - Ask questions, share ideas
- **[Stack Overflow](https://stackoverflow.com/questions/tagged/apiverve)** - Tag your questions with `apiverve`

## 🐛 Bug Reports

Found a bug? Please report it:
1. Check if it's already reported in [Issues](https://github.com/apiverve/apis/issues)
2. If not, [create a new issue](https://github.com/apiverve/apis/issues/new)

Include:
- API name
- Request details
- Expected vs actual behavior
- Error messages

## 📧 Direct Support

- **General inquiries:** [hello@apiverve.com](mailto:hello@apiverve.com)
- **Security issues:** [security@apiverve.com](mailto:security@apiverve.com)
- **Enterprise/Partnership:** [enterprise@apiverve.com](mailto:enterprise@apiverve.com)

## 🔑 Account & Billing

For account or billing questions:
1. Log in to your [Dashboard](https://dashboard.apiverve.com)
2. Use the support chat or email [billing@apiverve.com](mailto:billing@apiverve.com)

## ⏱️ Response Times

- **Documentation/FAQ:** Instant (self-service)
- **GitHub Issues:** 1-3 business days
- **Email Support:** 1-2 business days
- **Security Issues:** Within 48 hours
