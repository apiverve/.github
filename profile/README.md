## About APIVerve

We provide **356+ production-ready REST APIs** that developers can integrate in minutes. No complex setup, no infrastructure to manage - just simple, reliable APIs.

**Why developers choose us:**
- Simple API key authentication
- Generous free tier (100 requests/day)
- Official SDKs for Node.js, Python, .NET, and more
- 99.9% uptime SLA
- Fast global response times

## Official SDKs

Every API has official client libraries:

| Platform | Installation | Registry |
|----------|--------------|----------|
| **Node.js** | `npm install @apiverve/<api>` | [npm](https://www.npmjs.com/~apivervehq) |
| **Python** | `pip install apiverve-<api>` | [PyPI](https://pypi.org/user/apiverve/) |
| **.NET** | `dotnet add package APIVerve.API.<Api>` | [NuGet](https://www.nuget.org/profiles/APIVerve) |
| **Go** | `go get github.com/apiverve/<api>-go` | [GitHub](https://github.com/apiverve) |
