# .github

This repository contains organization-wide files for [APIVerve](https://github.com/apiverve).

## Organization Profile

The `profile/README.md` file is displayed on our [organization page](https://github.com/apiverve).

## Community Health Files

These files serve as defaults for all repositories in this organization:

| File | Purpose |
|------|---------|
| `CODE_OF_CONDUCT.md` | Community behavior standards |
| `CONTRIBUTING.md` | How to contribute to our projects |
| `SECURITY.md` | Security vulnerability reporting |
| `SUPPORT.md` | Where to get help |
| `LICENSE` | MIT License |
| `FUNDING.yml` | Sponsorship configuration |
| `ISSUE_TEMPLATE/` | Default issue templates |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template |

## How It Works

Files in this repository act as defaults for all repositories in the APIVerve organization. Individual repositories can override these by including their own versions.
